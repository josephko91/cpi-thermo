## 4. Potential issues

Open, unresolved items (see `CLAUDE.md`'s "Known issues" section for the
current list and `docs/dataset-changelog.md` for how the dataset arrived at
its present state):

- **ARM qv NaN** — 63.6% NaN. Real data sparsity in the dry upper
  troposphere, not a parser bug.
- **ARM 2000-03-13 CPI timestamp anomaly** — CPI has images at 00:00-01:xx
  UTC with no corresponding env data that date. Investigated; most likely a
  CPI-side ground-test/calibration session or clock fault, not a missing raw
  file. See `docs/decisions/2026-07-05-arm-cpi-timestamp-investigation.md`.
- **IPHEX/OLYMPEX cold-regime Si flags** (1,436 rows, QC9) — chilled-mirror
  hysteresis at extreme cold can amplify small errors into large fractional
  Si swings, but Si up to ~1.5-1.7 is also physically documented for real
  cirrus near the homogeneous-freezing threshold. Kept in the data, flagged
  via `cold_regime_amplification_candidate` in `09_lwc_crossval.csv`. Needs
  an independent cross-check (e.g. Ophir TDL) to resolve.
- **MIDCIX Alt_m** at 96.7% coverage (Tair/Si/qv lower, ~26-64% — see table
  above), not 100%: navigation (`FP`) files cover 2 more flight dates than
  the water-vapor (JW) files `load_midcix()` keys rows off of; JLH genuinely
  wasn't operating those 2 dates, so this is a real data gap, not a parser
  bug.
- **MPACE Si/qv = 0%** — no water-vapor instrument was flown on this
  platform (by design, not a bug); only Tair_C/P_hPa/Lat/Lon/Alt_m are
  populated for its 15 flights.
- **CRYSTAL-FACE-NASA (~44%) and CRYSTAL-FACE-UND qv/Si (~53%) fusion
  coverage** — genuine data limitations from hygrometer sampling gaps that
  anti-correlate with peak CPI activity (cloud penetrations); see items 5
  and 8 in `logs/cpi_fusion/latest/cpi_fusion_report.txt`.
