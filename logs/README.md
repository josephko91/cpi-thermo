# logs/ layout

Every diagnostic entry point writes to its own subfolder here, timestamped so a
new run never overwrites a previous one. The shared helper is
`scripts/log_paths.py` (`timestamp()` + `update_latest()`); see
[`CLAUDE.md`](../CLAUDE.md#logs--figs-layout) for the one-line-per-script table.

This whole directory is gitignored except this file (`logs/*` + `!logs/README.md`
in `.gitignore`) — everything below is regenerated by running the pipeline, so
none of it is version-controlled.

## Subfolders

- **`pipeline/<YYYYMMDD_HHMMSS>/`** — output of `python main.py` (the full
  parser run). Contains `output.log` plus the three campaign-level diagnostic
  CSVs (`campaign_summary.csv`, `si_instrument_coverage.csv`,
  `qv_instrument_coverage.csv`) written by `generate_diagnostics()`.

- **`qaqc/<YYYYMMDD_HHMMSS>/`** — output of `python scripts/qa_checks.py`, the
  9 QC checks (`00_qaqc_summary.csv` through `09_lwc_crossval.csv`).

- **`cpi_fusion/<YYYYMMDD_HHMMSS>/`** — output of
  `python scripts/diagnose_cpi_fusion.py`: `cpi_fusion_summary.csv` (per-campaign,
  per-variable coverage of the CPI image archive) and `cpi_fusion_report.txt`
  (same numbers as prose, plus the running list of known fusion issues).

- **`campaign_missingness/<YYYYMMDD_HHMMSS>/`** — output of
  `python scripts/diagnose_campaign_missingness.py`, which audits *why* a
  standardized variable is missing for a campaign (absent in the raw file vs.
  dropped by the extractor vs. masked by cleaning). Chained into by
  `scripts/summarize_parser_recommendations.py`, which reads
  `campaign_missingness/latest/` by default to print a ranked parser-fix backlog.

- **`campaign_tests/<campaign>/<YYYYMMDD_HHMMSS>/`** — output of the one-off
  per-campaign deep-dive scripts in `scripts/tests/` (currently
  `test_attrex.py`, `test_ice_l.py`, `test_iphex.py`). Timestamped like
  everything else since 2026-07-06 (with a `latest` symlink), but the
  directory is created lazily inside the test function that writes to it
  (`test_write_diagnostics`/`test_generate_figures`) rather than at module
  import time — so just collecting the test file (e.g.
  `pytest --collect-only`) doesn't spam empty run folders.

- **`archive/`** — everything that existed before the 2026-07-06 reorg
  (undated `diagnostics/` dumps that used to be shared by multiple unrelated
  scripts, ad hoc `output_*.log` files, etc.), moved here as-is so nothing was
  lost. Not added to going forward.

## The `latest` symlink

Each timestamped bucket (`pipeline/`, `qaqc/`, `cpi_fusion/`,
`campaign_missingness/`, `campaign_tests/<campaign>/`) keeps a `latest`
symlink pointing at its newest run, e.g. `logs/qaqc/latest -> 20260706_134049/`.
Use it when you just want the most recent results without knowing the exact
timestamp:

```bash
cat logs/cpi_fusion/latest/cpi_fusion_report.txt
```
